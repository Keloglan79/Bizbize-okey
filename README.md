# Bizbize Okey — ücretsiz yayın

Bu klasör hem oyunu hem online masa sunucusunu içerir.

GitHub'a yükle. Render'da ücretsiz Web Service aç, depoyu bağla.
Start komutu: `npm start`
Health check path: `/health`

Site adresi hem tek oyunculu hem çok oyunculu masadır.
Telefonda tarayıcıdan aç, ana ekrana ekle. Ayrı mağaza hesabı gerekmez.
